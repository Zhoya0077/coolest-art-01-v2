# The Bell Demon — coolest-art-01 (v2)

An original yokai illustration in a bold streetwear-graphic style: a haunted
temple bell with one huge bloodshot eye, a fanged grin, ghost arms, and
flames on a pure black background.

## Entry

`main.py` copies `entry.png` byte for byte to the grader output directory,
so every run produces identical output. The artwork is JPEG data under a
`.png` name; the format is told apart by magic bytes.

## Files

- `main.py` — the entry program (standard library only)
- `entry.png` — the artwork (1024x1024 JPEG)
- `LICENSE` — starter license
